# EventIQ Demo Application

This is a simple demo HTML application designed to test the EventIQ SDK integration.

## Usage

Simply open `index.html` in your browser or serve it using a local static file server.

```bash
npx serve .
```

## Features
- Includes sample forms (with automatic data redaction demonstrations).
- Examples of `data-eventiq-ignore` usage.
- Simulates Single Page Application (SPA) navigations.
